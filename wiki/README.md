# Project Wiki documentation

Start with the [project overview](Home.md), or choose a topic from the
[navigation index](_Sidebar.md).

These Markdown pages are stored in the source repository under `wiki/` and can
be read directly on GitHub or in VS Code. Their relative links include `.md` so
navigation works in the repository.

GitHub also provides a separate Wiki tab backed by its own Git repository.
Adding files here does not initialize or publish that separate Wiki. If these
pages are copied there later, adapt the links to GitHub Wiki page names and
keep this repository-specific note outside the published Wiki.
